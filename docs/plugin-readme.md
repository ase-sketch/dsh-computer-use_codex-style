# dsh-computer-use

**The full README is at the repository root: [README.md](../README.md) (English) and [README.zh-CN.md](../README.zh-CN.md) (中文).**

This file only records the two package entry points for people already inside the repository:

- HOST plane: `dsh-computer-use` — the process-wide desktop sidecar, published as the `dshComputerUse` service (pointer, overlay, capture, approvals, turn lifecycle, experience layer).
- PRESET plane: `dsh-computer-use/tool` — the 13 window2 tools plus the harness extensions; mount it in an agent preset, next to the `skills/` copies.

Install, configure and verify from the root README; nothing here is required reading for a user.
